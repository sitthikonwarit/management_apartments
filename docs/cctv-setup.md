# ตั้งค่ากล้องวงจรปิดให้ขึ้นบนเว็บ

เบราว์เซอร์เล่น RTSP ของ DVR ตรงๆ ไม่ได้ และ DVR อยู่ที่หอพักคนละที่กับเซิร์ฟเวอร์เว็บ จึงต้องมี "ตัวกลาง" 1 ตัวที่หอพัก:

```
DVR (Dahua) --RTSP--> [คอมที่หอพัก: go2rtc + ffmpeg] --MJPEG ผ่าน Tailscale--> [เซิร์ฟเวอร์เว็บ] --พร็อกซี+ล็อกอิน--> เบราว์เซอร์
```

ไม่ต้องเปิดพอร์ต DVR ออกอินเทอร์เน็ต และเบราว์เซอร์ไม่เคยเห็นที่อยู่กล้อง/รหัสผ่านจริง

## 1) เครื่องที่หอพัก (เปิดทิ้งไว้ตลอด)
คอม Windows/มินิพีซี/Raspberry Pi ที่อยู่เครือข่ายเดียวกับ DVR

1. ติดตั้ง **Tailscale** (tailscale.com) ล็อกอินบัญชีเดียวกับที่จะใช้บนเซิร์ฟเวอร์เว็บ แล้วจดไอพี `100.x.x.x` ของเครื่องนี้
2. ดาวน์โหลด **go2rtc** (github.com/AlexxIT/go2rtc/releases) และ **ffmpeg** (วางไว้ใน PATH หรือโฟลเดอร์เดียวกัน)
3. สร้างไฟล์ `go2rtc.yaml`:

```yaml
api:
  listen: "100.x.x.x:1984"   # ฟังเฉพาะไอพี Tailscale ของเครื่องนี้ ห้ามใช้ 0.0.0.0

streams:
  # Dahua: channel = หมายเลขกล้อง, subtype=1 = สตรีมรอง (ภาพเล็ก ลื่น ประหยัดเน็ต) / subtype=0 = สตรีมหลัก
  cam5: ffmpeg:rtsp://USER:PASS@192.168.1.108:554/cam/realmonitor?channel=5&subtype=1#video=mjpeg
  cam6: ffmpeg:rtsp://USER:PASS@192.168.1.108:554/cam/realmonitor?channel=6&subtype=1#video=mjpeg
  cam7: ffmpeg:rtsp://USER:PASS@192.168.1.108:554/cam/realmonitor?channel=7&subtype=1#video=mjpeg
  cam8: ffmpeg:rtsp://USER:PASS@192.168.1.108:554/cam/realmonitor?channel=8&subtype=1#video=mjpeg
```

   แทน `USER:PASS` และ `192.168.1.108` ด้วยบัญชี/ไอพี DVR จริง (ตัวเดียวกับที่ใช้ใน Smart PSS) ถ้ารหัสผ่านมีอักขระพิเศษ เช่น `@` ให้เข้ารหัสแบบ URL (`@` = `%40`)
4. รัน `go2rtc` ให้ทำงานอัตโนมัติตอนเปิดเครื่อง (Windows: Task Scheduler / NSSM)
5. ทดสอบ: เปิด `http://100.x.x.x:1984/api/stream.mjpeg?src=cam5` ในเบราว์เซอร์ที่ติด Tailscale ควรเห็นภาพสด

## 2) เซิร์ฟเวอร์เว็บ
ติดตั้ง Tailscale ล็อกอินบัญชีเดียวกัน แล้วเช็คว่าเรียก `curl -I http://100.x.x.x:1984/` ได้

## 3) บนเว็บ
เมนู **กล้องวงจรปิด** → **เพิ่มกล้อง** → ชื่อ เช่น `CAM 5` และ URL
`http://100.x.x.x:1984/api/stream.mjpeg?src=cam5` (ทำซ้ำสำหรับแต่ละกล้อง)

## หมายเหตุ
- ใช้สตรีมรอง (subtype=1) สำหรับตารางหลายกล้อง ภาพเล็กพอและกินเน็ตน้อย ถ้าอยากดูชัดแบบเต็มจอ ให้เพิ่มกล้องอีกรายการที่ใช้ subtype=0
- เน็ตของหอพักต้องมีความเร็วอัปโหลดพอ (โดยประมาณ 0.5–1.5 Mbps ต่อกล้องต่อคนที่เปิดดู) ปุ่ม "หยุดดู" บนหน้าเว็บปิดการเชื่อมต่อทุกกล้อง
- ถ้า nginx หน้าเซิร์ฟเวอร์ตัดสตรีมค้าง ให้เพิ่มใน location ของ `/api/`: `proxy_buffering off; proxy_read_timeout 3600s;`
- ผู้ที่ล็อกอินเข้าเว็บได้ทุกคนจะเห็นกล้อง
